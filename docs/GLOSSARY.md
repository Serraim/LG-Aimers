# 용어 고정표

> 여기 적힌 이름만 쓴다. 같은 것을 다른 이름으로 부르지 않는다.
> 숫자는 전부 우리가 실제로 측정한 값이다 (2026-08-17).

---

## 한 줄 요약

```
점수 = 변별력점수 − 중심손실
```

**우리가 할 수 있는 일은 딱 두 가지다.** 변별력을 올리거나, 중심손실을 없애거나.

```
중심손실   2026-08-17 에 0 으로 만들었다.  끝난 축
변별력     남은 전부
```

---

## 고정 용어 5개

| 이름 | 기호 | 뜻 | 현재 값 |
|---|---|---|---|
| **실제 성공률** | `r` | 2025 평가 데이터의 진짜 제구 성공 비율 | **0.4609** |
| **불확실성** | `K` | 아무것도 모를 때의 오차. `r(1-r)` | **0.248470** |
| **Brier** | `B` | 우리 예측의 실제 오차. 작을수록 좋다 | 모델마다 |
| **중심오차** | `A` | 우리 예측 평균 `m` 에서 `r` 을 뺀 값 | 모델마다 |
| **변별력** | `V` | 공마다의 차이를 얼마나 맞히나. 클수록 좋다 | 모델마다 |

### 쓰지 않을 이름

```
분해능, resolution        -> 변별력 으로 통일
신뢰도, reliability       -> 중심오차 로 (우리가 다루는 건 그 부분뿐)
prior, 사전확률           -> 중심 또는 예측평균 m 으로
캘리브레이션, 보정        -> 중심 보정 으로
```

## 하나씩

<details open>
<summary><b>r — 실제 성공률</b></summary>

**2025 경기에서 실제로 제구가 성공한 비율.** 24만 개 공 중 몇 %.

```
2019 .5647   2020 .5327   2021 .5328
2022 .5289   2023 .5000   2024 .4861
2025 .4609
```

### 어떻게 나온 값인가

같은 모델에 상수 `c` 를 더해 제출한 세 점의 점수로 채점식의 미지수를 풀었다.
(`c` = 0 / -0.014 / -0.040, 제출 49778 / 51932 / 51948)

**이 방식은 2026-08-19 에 운영진에 자진 문의해 허용 범위로 답변받았다.**
다만 **"정답 특성을 역으로 추정하려는 수준의 반복 프로빙은 권장하지 않는다"**는
안내를 함께 받았다.

```
계속 쓸 것    이미 얻은 이 값으로 현재 모델의 중심을 맞추는 것
하지 않을 것  이 값을 더 정밀하게 만들려는 추가 제출
              구간별로 나눠 여러 값을 캐내는 것
```

**자세한 선은 `docs/RULES_LB_PROBING.md` 참고. 새 실험 전에 반드시 읽는다.**

</details>

<details open>
<summary><b>K — 불확실성 (채점 분모)</b></summary>

```
K = r x (1-r) = 0.4609 x 0.5391 = 0.248470
```

**"모든 공에 그냥 46.09% 라고 찍었을 때의 오차"** 다.
채점식의 기준선이고, 우리 점수는 여기서 얼마나 나아졌나로 정해진다.

```
점수 = 100000 x (1 − Brier / K)
```

Brier 가 K 와 같으면 0점. 작을수록 점수가 오른다.

</details>

<details open>
<summary><b>A — 중심오차</b></summary>

```
A = m − r        m = 우리 예측들의 평균
```

**우리 예측이 통째로 위나 아래로 밀린 정도.** 개별 판단이 아니라 눈금 자체의 어긋남.

```
S06 (우리 ENS-3)      m = 0.4737   A = +0.01280
E08   (baek-32)         m = 0.46779  A = +0.00689
```

### 왜 생기나

시즌 성공률이 계속 내려가는데 **나무 모델은 학습 범위 밖으로 못 나간다.**
`season=2025` 행은 전부 2024 잎에 떨어져서, 2024 수준으로 예측한다.

### 벌점

```
중심손실 = 100000 x A² / K
```

**제곱이라 빨리 커진다.**

```
A = 0.005  ->   10 점
A = 0.010  ->   40 점
A = 0.013  ->   66 점      <- 우리 S06 이 버리던 양
A = 0.020  ->  161 점
```

### 고치는 법

`script.py` 에서 모든 예측에 상수 `-A` 를 더한다. **한 줄이다.**

```python
return np.clip(values + SHIFT, 0.0, 1.0)
```

test 의 다른 행을 보지 않는 고정 상수이므로 행 독립성 규칙을 지킨다.

</details>

<details open>
<summary><b>V — 변별력</b></summary>

**"이 공은 되고 저 공은 안 된다"를 구분하는 능력.** 우리가 실제로 아는 양.

```
V = K − (B − A²)
```

`B − A²` 는 중심을 완벽히 맞췄을 때의 Brier 다. 그것과 K 의 차이가 변별력.

```
V = 0        모든 공에 같은 확률.  점수 0
V 가 클수록  공마다 다른 확률을 제대로 준다는 뜻
```

### 현재

```
S06 (우리 ENS-3)   V = 0.002174   ->  874.98 점
E08   (baek-32)      V = 0.002261   ->  909.78 점
                                        차이 4%,  점수로 35점
```

### 변별력은 피처로만 오른다

중심 보정으로는 절대 안 오른다. 상수를 더해도 순서와 간격이 그대로이기 때문이다.

**그리고 로컬에서 올린 변별력은 LB 로 그대로 간다.**

```
로컬 2024 에서 잰 값     0.001895
2025 LB 실측             0.002174
비율                     115%
```

</details>

## 두 축으로 쪼개는 법

LB 점수 하나만 있으면 아무것도 모른다. **`K` 를 알면 두 개로 쪼갤 수 있다.**

```
1.  B = K x (1 − 점수/100000)
2.  A 는 과거 S07~S10에서 같은 모델의 복수 제출로 측정했다
3.  V = K − (B − A²)
```

### 실제 예

```
S06   LB 809.02  =  874.98 (변별력)  −  66.0 (중심손실)
E08     LB 890.68  =  909.78 (변별력)  −  19.1 (중심손실)
S10   LB 909.78  =  909.78 (변별력)  −   0.0 (중심 보정 완료)
```

---

## 측정 원리

```
Brier(c) = Brier(0) + 2c·A + c²
```

**`c²` 의 계수가 정확히 1 이다.** 맞출 필요가 없는 상수다.
그래서 미지수는 `A` 와 `K` 둘뿐이고, 제출 3회면 정확히 풀린다.

우리는 서로 다른 두 모델로 각각 풀어 같은 `K` 를 얻었다.

```
S06 세 점으로   K = 0.248470
E08   세 점으로   K = 0.248471
```

## 운용 규칙

```
r, K       한 번만 재면 된다.  모든 모델이 공유.  끝났다.  추가 측정 안 함
A          모델마다 다르다.  다른 모델의 A 를 옮겨 쓰지 않는다  <- S09 실패 사례
V          로컬에서 재고 LB 로 확인한다.  115% 전달
```

### 새 모델의 중심을 맞출 때 (2026-08-19 이후 절차)

**방정식을 풀거나 LB에서 보정 후보를 고르지 않는다.**

```
1  학습 데이터로 그 모델의 2024 중심오차를 먼저 잰다
2  2024 실제 평균으로 정한 보정값을 그대로 쓴다
3  같은 모델에 상수만 바꾼 추가 제출은 하지 않는다
4  점수를 버리는 진단 전용 제출은 하지 않는다
```

**모든 제출은 "더 좋은 모델을 고르기 위한 것"이어야 한다.**
`docs/RULES_LB_PROBING.md` 참고.

**새 모델의 중심오차와 중심 제거 성능은 2024 검증 결과로 기록한다.**
