## 운영진 답변 원문

> 문의주신 방식은 학습 데이터에서 확인한 시즌별 성공률 추세를 바탕으로
> 보정 필요성을 판단한 뒤, 현재 가장 많이 발생하고 있는 타 행의 평가 데이터
> 자체를 직접 활용한 것이 아니라 리더보드에서 공식적으로 제공되는 점수를
> 활용한 경우이므로, **말씀해주신 정도의 후보값 비교·보간은 허용되는 범위로
> 판단합니다.**
>
> 다만, 리더보드 점수 역시 평가 데이터를 기반으로 산출되는 만큼,
> **이를 과도하게 반복 활용하여 평가 데이터의 정답 평균·분포 등 정답 특성을
> 역으로 추정하려는 수준의 리더보드 프로빙은 권장하지 않습니다.**

## 무엇이 허용을 갈랐나

답변에서 허용 근거로 든 것이 셋이다.

```
1. 학습 데이터에서 확인한 추세를 바탕으로 보정 필요성을 판단했다
2. 평가 데이터의 타 행을 직접 활용하지 않았다
3. 리더보드가 공식적으로 제공하는 점수를 썼다
```

**우리가 이 셋을 다 만족했다.**

```
1  시즌 성공률 하락(.5647 -> .4861)을 학습 데이터에서 먼저 확인
   나무가 외삽을 못 한다는 구조적 이유도 학습 데이터로 파악
2  추론 코드가 test 다른 행을 참조하지 않음. 행 독립성 차이 0.0
3  제출 점수만 사용. 외부 데이터 없음
```

## 앞으로의 선

### 계속 해도 되는 것

```
학습 데이터로 보정의 필요성과 대략적 크기를 먼저 정한다
후보값 2~3개를 제출해 점수가 좋은 것을 채택한다
모델 / 하이퍼파라미터 / 앙상블 가중치를 리더보드로 선택한다
```

**제출의 목적이 "이 모델 후보가 더 좋은가"여야 한다.**

### 하지 않는다

```
점수를 버리는 진단 전용 제출          <- S08(-0.040, 577점)이 그것이었다
구간을 나눠 여러 상수를 캐내는 것      (월별, 리그별, 투수별 ...)
이미 얻은 값을 더 정밀하게 만들려는 반복 제출
정답의 평균/분포/특성을 더 알아내려는 목적의 제출
```

**"권장하지 않는다"는 표현이지만 선을 넘지 않는다.**
Phase 3 검증에서 도출 근거와 과정을 확인한다고 명시돼 있다.

### 판단 기준 한 줄

```
이 제출이 "더 좋은 모델을 고르기 위한 것"인가,
아니면 "평가 데이터에 대해 더 알기 위한 것"인가
```

**후자면 하지 않는다.**

## 이미 얻은 값의 취급

```
r = 0.4609,  K = 0.248470
```

**이미 도출된 값이므로 지금 있는 모델의 중심 보정에는 계속 쓴다.**
**단 이 값을 더 정밀하게 만들려는 추가 제출은 하지 않는다.**

앞으로 새 모델의 중심을 맞출 때는 이렇게 한다.

```
1  학습 데이터로 그 모델의 2024 중심오차를 먼저 잰다
2  2024 실제 평균으로 정한 보정값을 그대로 쓴다
3  방정식을 풀어 값을 도출하지 않는다
4  같은 모델에 상수만 바꾼 추가 제출은 하지 않는다
```
