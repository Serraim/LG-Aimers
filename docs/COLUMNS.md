### 6. `폭` 은 신호의 크기가 아니다. 잡음과 비교해야 한다

<details>
<summary><b>6-a. 잡음 공식은 군집 보정을 해야 한다</b></summary>

처음 쓴 `2 x sqrt(0.25/n)` 은 **투구 하나하나가 독립이라고 가정한다. 아니다.**
같은 투수가 그날 던진 100구는 서로 닮았다.
147만 개의 독립 관측이 아니라 **600여 명이 뭉텅이로 만든 관측**이다.

```
                       단순 공식    투수 군집(정직)   배율
41명 코호트 6년 변화     0.0063       0.0190          3.0배
game_type R              0.0009       0.0052          5.8배
game_type F              0.0025       0.0093          3.7배
```

**단순 공식은 잡음을 3~6배 과소평가한다.**

```
쓸 것   군집 강건 표준오차 (cluster-robust, 군집 = pitcher_id)

        Var(p) = sum_g ( sum_{i in g} (y_i - p) )^2 / n^2
        잡음 기대(95%) = 2 x sqrt(Var(p))
```

`scripts/read_group.py` 가 이 값을 계산한다. 단순 공식도 같이 찍어 배율을 본다.

### 10. 단독으로 잡음이어도 조합에서는 신호일 수 있다

단독 성공률 표는 **주변부(marginal) 평균**이다. 다른 컬럼을 전부 뭉개고 평균 낸
값이므로 **상호작용은 원리적으로 보이지 않는다.**

```
A    B    성공률          A 단독:  A=0 -> 0.5,  A=1 -> 0.5
0    0     0.9            B 단독:  B=0 -> 0.5,  B=1 -> 0.5
0    1     0.1
1    0     0.1            둘 다 완벽한 잡음으로 보인다
1    1     0.9            그런데 합치면 100% 맞춘다
```

우리 데이터의 증거:

```
S 그룹 6개            중요도 합 1.9%  ->  빼니까 -26.33
success_shrunk 혼자   -6.34           ->  15개 함께 +102.16
```

유력한 후보는 `outs_before` 다.

```
2아웃 + 3루 주자    삼진 노림. 존 밖 유인구
0아웃 + 3루 주자    스퀴즈 경계. 스트라이크 필요
```

**아웃 카운트 단독 평균에서는 이 둘이 상쇄된다.**

| 구별 방법 | 비용 | 보이는 것 | 한계 |
|---|---|---|---|
| 교차표 2개씩 | 공짜 | 2차 상호작용 | 칸이 쪼개져 잡음 폭증. 3개 이상 불가 |
| 나무 경로 동반 빈도 | 싸다 | 실제로 쓰인 상호작용 | 나무가 이미 찾은 것만 |
| 그룹 제거 실험 | 제출 1회 | 전부 | 이유는 안 알려줌 |

**우열이 아니라 순서다.**

### 12. 시즌마다 방향이 뒤집히면 평균은 무의미하다 ★

**규칙 7(시즌 통제)만으로는 부족했다.** 통제하고 평균을 내도 이 함정에 빠진다.

`game_type` 이 그 사례다. 6시즌 평균 편차는 **+8.01%p** 였는데:

```

2022 +0.2051   2023 -0.0302   2024 -0.0304
```

**2023 에 부호가 뒤집혔다.** 앞의 넷이 뒤의 둘을 압도해 평균이 양수로 나왔다.

```

2023-24 만으로 재면 -3.08%p (군집잡음의 2.9배)
크기는 4분의 1, 부호는 반대.
```

#### 검사 방법

```
값마다 시즌별 편차를 늘어놓고 부호가 섞이는지 본다.
섞이면 6년 평균을 버리고 최근 2시즌으로 다시 잰다.
```

`scripts/read_group.py` 로 잰 뒤 반드시 이 검사를 한다.

#### 주의 — 최근 2시즌은 표본이 3분의 1이다

**잡음이 1.7배로 커진다.** 그래서 "잡음"으로 나온 것이
정말 없는 것인지 표본이 줄어서인지 구별되지 않는다.
**단조 추세는 칸별 검정으로 판정하지 않는다** (이닝이 그 예다).

### 11. 기존 파생 15개는 근거가 될 수 없다

**S단계를 하는 이유가 그 15개를 못 믿어서다.**

```

        -> 의심 대상을 판정 근거로 쓰는 순환논증

허용    원본 49컬럼만으로 잰 것
